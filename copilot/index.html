    Copilot 使用指南

    本页整理一些常见的 Copilot 使用方式，帮助你更快完成文档、代码和问题排查。

    1. 先说明目标，再让 Copilot 帮你拆解

    当你要 Copilot 帮忙时，尽量把目标、限制和输出格式说清楚：

    • 目标：要做什么
    • 限制：语言、风格、长度、技术栈
    • 输出：希望得到清单、示例、代码或改写结果

    示例：

    请把这段文档改写成更适合新手阅读的中文说明，保留原有结构，输出 Markdown。

    2. 用它做重复性工作

    Copilot 很适合处理这些场景：

    • 生成文档初稿
    • 总结长段落
    • 改写说明文字
    • 补充示例代码
    • 给现有内容做格式整理

    3. 配合检查，而不是直接照抄

    Copilot 生成的内容最好经过你自己再确认：

    1. 看是否符合当前上下文
    2. 检查是否有过时内容
    3. 确认示例能运行或能被正确理解
    4. 视情况再做人工润色

    4. 常用提示词模板

    请根据下面的内容总结 3 个要点。

    请把这段内容改成适合 PR 描述的版本，语气简洁。

    请基于这个错误信息，列出可能原因和排查步骤。

    5. 小结

    Copilot 更适合做“辅助起草”和“加速整理”，最终内容仍然要由你来判断和确认。这样既能提升效率，也能保证输出质量。
